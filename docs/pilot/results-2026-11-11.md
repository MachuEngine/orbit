# 모델 파일럿 결과 (2026-11-11, OpenAI 직접 호출)

근거: ADR-0009, ADR-0010(구조화된 답 채점), ADR-0014(임시 OpenAI). 결정은 ADR-0015.
결과 원본(`runs/pilot/*.jsonl`)은 git에서 제외한다. 이 문서에는 집계값만 둔다.

## 조건
- 데이터: `eval/datasets/orbit-eval/v0`, **dev 36문항**(근거 공유 묶음 6개), 개발자 전수 검수 완료. test는 봉인 상태로 실행하지 않았다.
- 평가 대상: `assistant_v0`(프롬프트 `assistant-v0.2`), 읽기 도구 4개 + `submit_answer`, Sim 커넥터.
- 반복: 과제당 3회, 반복 우선 순서, 시드 0. 신뢰구간은 묶음 단위 bootstrap 10,000회.
- 실행: 2026-11-11, OpenAI Responses API, `store=false`, 모델 ID는 공개 스냅샷이 없어 별칭이다. 세 실행 모두 응답 모델이 선언 모델과 같았다(불일치 0).

## 해석
- C는 A·B보다 성공률이 높고, 짝지은 차이의 신뢰구간이 0을 포함하지 않는다.
- A와 B의 차이는 신뢰구간이 0을 포함한다. 이 데이터로는 luna의 추론 강도(none↔low) 효과를 말할 수 없다. 또 이 실행에서는 추론 토큰을 결과에 기록하지 않아(이후 수정) low 설정에서 추론이 실제로 얼마나 쓰였는지 확인하지 못했다.
- luna의 실패는 인물 다음 미팅(동명이인 구분, 메일 서명으로 소속 확인)과 프로젝트 주간 목록에 몰려 있다. 형식 실패(`answer_format`)의 대부분도 인물 과제에서 나왔다.

## 한계
- **천장 효과**: C가 dev 전체를 맞혀, 이 데이터로는 C 위에서 패턴·프롬프트 개선 효과를 측정할 수 없다. 이후 비교(8단계)에는 더 어려운 과제(캘린더와 메일이 어긋나는 유형, 다중 턴, 쓰기)가 필요하다.
- 묶음이 6개라 신뢰구간이 불안정하다(통계 경고). 문항 수 36은 작다.
- 모델 ID가 별칭이라 같은 ID라도 시간이 지나면 가중치가 바뀔 수 있다(ADR-0014). 날짜를 함께 기록한다.
- 후보가 OpenAI 모델 3안뿐이다. OpenRouter 연결 후 여러 제공자 모델을 같은 조건으로 추가 비교한다.
