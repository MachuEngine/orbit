# ADR-0015 — 임시 고정 모델: 실험·실사용 모두 `gpt-6-luna`(low)

- 상태: 채택 (2026-11-11, 임시. 개발자 결정: 실험 기본은 B, 실사용은 C. OpenAI 사용은 임시이며 OpenRouter 연결 후 여러 모델을 비교해 다시 정한다)
- 개정: 2026-11-15, 개발자 결정으로 실사용도 B(`gpt-6-luna` low)로 바꿨다. 아래 "변경 기록" 참고
- 작성일: 2026-11-11
- 근거: ADR-0009(평가 기반), ADR-0014(OpenAI 직접 호출), `docs/pilot/results-2026-11-11.md`

## 결정
| 용도 | 모델 · 설정 | 근거 |
| --- | --- | --- |
| **실험·개발 기본** (평가 러너, 패턴·프롬프트 비교) | `openai/gpt-6-luna`, `reasoning.effort=low`, temperature 미전송 | dev 성공률 75.9%(95% CI 60.2–91.2)로 개선 효과를 측정할 여지가 있고, 에피소드당 약 0.00036달러로 반복 실험이 가능하다 |
| **실사용·시연** (웹 화면, 워커) | `openai/gpt-6-luna`, `reasoning.effort=low`, temperature 미전송 | 2026-11-15 변경. 비용을 줄이려고 실험 기본과 같은 모델을 쓴다. 에피소드당 약 0.00036달러(terra 약 0.0053달러). 품질 저하는 아래 변경 기록에 적었다 |

- 모델은 설정 값(`ORBIT_LLM_MODEL_ID`, `ORBIT_LLM_REASONING_EFFORT`)으로만 바꾼다. 코드에 모델을 고정하지 않는다.
- 실험 결과를 보고할 때는 "기준 모델 위에서 측정"을 명시하고, 결과의 설정 지문(모델·추론 강도·단가)으로 구분한다. 서로 다른 기준 모델의 결과를 한 비교에 섞지 않는다.
- 실행마다 응답 모델 값과 날짜를 결과에 기록한다(공개 스냅샷 없음).

## 검토한 대안
| 대안 | 채택하지 않은 이유 |
| --- | --- |
| 모든 용도에 terra | dev에서 천장 효과(100%)라 개선 효과를 측정할 수 없고, 반복 실험 비용이 약 15배다 |
| 모든 용도에 luna | (2026-11-11 기각, 2026-11-15 채택으로 바뀜) 인물 다음 미팅 과제 성공 5/18 등 실사용 품질이 낮다 |
| luna effort none(A)을 실험 기본으로 | B와의 차이는 통계적으로 구분되지 않는다(+1.9%p, CI −3.6~+5.9). 비용은 거의 같고 B의 지연 p90이 더 짧다(10.3s vs 14.4s) |
| 상위 모델(`gpt-6.1-sol`, `gpt-6-astra`) | 예산(10달러)을 넘을 위험이 크다 |

## 결과와 후속
- 평가 데이터 v1(어려운 유형 추가)을 만들면 두 모델 모두 다시 측정한다.
- 재검토 트리거: OpenRouter 연결(다제공자 비교), 평가 데이터 v1, OpenAI 모델·가격 변경.

## 변경 기록
### 2026-11-15 — 실사용 모델을 `gpt-6.1-terra`에서 `gpt-6-luna`(low)로
- 개발자 결정. 실사용 비용을 줄이는 것이 목적이다. 단가는 입력 1→0.10, 캐시 입력 0.05→0.01, 출력 5→0.50달러/1M 토큰이다.
- 감수하는 품질 저하(같은 v0 dev 36문항 기준, 2026-11-11 파일럿): 성공률 100% → 75.9%(95% CI 60.2–91.2). 인물 다음 미팅 과제 18/18 → 5/18, 프로젝트 주간 18/18 → 12/18. 실사용 경로(`runflow_v0`)에서 luna는 61.1%였다(`docs/pilot/results-2026-11-15-runflow-v0.md`).
- 실사용과 실험이 같은 모델을 쓰므로, 이후 실사용 경로 품질 개선(프롬프트·추론 항목 등)의 효과는 같은 기준 모델 위에서 측정할 수 있다.
- 모델 선택은 여전히 설정 값으로만 한다. 바꾼 곳: `scripts/dev-run.sh` 기본값과 단가, `.env.example` 설명.
- 재검토 트리거는 위와 같다. 실사용 품질이 문제가 되면 terra로 돌아가거나 OpenRouter 후보를 비교한다.
