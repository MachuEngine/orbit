# 평가 결과 v1 — dev 비교와 검색 test 기록

기록일: 2026-11-17. 종단 설정 비교는 완료된 **dev 결과만** 다룬다. 종단 test 확인은 실행 중이며 추후 채운다. 이 문서를 작성하면서 LLM·임베딩·Judge·검색을 실행하지 않았다.

## 데이터셋과 채점

- 종단 과제 v1은 생성 시 240개다. 사람 검수에서 22개를 제외해 유효 과제는 **dev 88개 + 봉인 test 130개 = 218개**다. test는 독립 묶음 102개, dev는 73개다. 매니페스트의 생성 전 분할 수와 봉인·검수 후 수를 구분한다(ADR-0026).
- dev 비교는 같은 88과제 × 3회 = 설정당 264에피소드다. 다중 턴은 dev 9대화(27에피소드)이며 기존 데이터에는 중간 턴별 정답이 없다. 스모크 목록은 생성 시 25개, 검수 제외 후 21개다.
- 검색 질의는 생성 180개에서 검수 제외 47개를 뺀 **133개(dev 55, test 78)**다. 메일만 색인하므로 문서 정답 질의를 더 빼면 메일 검색 평가는 dev 37개·13묶음, test 51개·19묶음이다(ADR-0028).
- 성공은 구조화된 답, 최종 상태, 궤적·승인 규칙으로 판정한다. 과제의 반복 평균을 구하고 근거를 공유하는 cluster 단위 bootstrap 95% CI를 낸다. 짝 차이는 같은 과제·반복을 맞춘 A−B다. 반복 264개를 독립 표본으로 취급하지 않는다(ADR-0010).

## dev 설정 비교

이 표의 비교 기준은 당시 측정한 **runflow_v0 · react · luna · 색인 끔(0.49)**이다. 이후 채택한 ADR-0031 기준은 **luna · react · 색인 켬(0.64)**이다. 아래 차이를 색인 켬 대비 차이로 읽으면 안 된다. haiku·gemini는 각각 `anthropic/claude-haiku-5.5`, `google/gemini-3.5-flash-lite`다. luna는 `openai/gpt-6-luna`, 추론 강도 `none`이며 실제 제공자 요청은 온도를 보내지 않았다. OpenRouter 모델의 추론 강도는 설정되지 않았다. 실사용 `low`와 같은 조건이 아니다.

plan의 비용은 비용을 알 수 있는 253에피소드의 합이다(11개 비용 미상). 성공 1건당 비용 역시 비용을 아는 성공 99건만 분모에 넣는다. 다른 설정은 264건 모두 비용을 기록했다. 비용 미상 11건을 LLM 오류 11건으로 해석하지 않는다.

## 검색 세트 test 결과

완료된 기존 `retrieval/test-openai-v1.json`을 전사했다. test 실행 횟수 1회, 검수 전 test 105개 → 검수 제외 27개 → 78개 → 문서 정답 27개 제외 → 메일 질의 **51개·19묶음**이다. 문서 검색 능력이나 종단 성공률과는 별도다. `text-embedding-3-small`, 800자 청크·100자 겹침, Kiwi, hybrid RRF k=60이며 각 메일함의 기존 색인을 재사용했다. 아래 recall은 등급 2 정답 기준이고 nDCG는 등급 관련도를 사용한다.

## Judge 간 일치도

기준선 두 경로(assistant·runflow) 528에피소드에 사후 적용한 기존 `judge/agreement-ab.json`의 에피소드 grounded 이진 판정을 읽었다. A는 haiku 계열, B는 gemini-2.5-flash-lite 계열이다. B의 판정 없는 16개를 제외한 **512개·73묶음**에서 일치율 0.645, **Cohen's kappa 0.10 [0.003, 0.203]**다. 기준 0.6에 미달한다. A의 grounded는 341/528, B는 431/512다. 서로 주장을 나누는 방식이 달라 주장 단위 일치도로 바꾸어 해석하지 않는다.

이 값은 **Judge끼리의 일치도**이며 사람과의 일치도가 아니다. 사람 라벨 검증은 미완료다. Judge 근거성 점수는 모델·설정 선정의 확정 지표로 사용하지 않는다.

## 한계와 후속 확인

- 생성 모델 문체·작은 유형별 표본·검수 기준점 효과, 공개된 test 정답, 반복 실행 및 dev 다중 비교의 과적합 위험이 있다. 묶음 수는 반복으로 늘지 않는다.
- assistant_v0는 읽기 전용이고 쓰기·문서·리마인더 등 runflow와 지원 범위가 다르다. 전체 0.42는 같은 기능을 갖춘 대체 구현의 점수가 아니다.
- 중간 턴 정답이 없어 다중 턴 수치는 마지막 구조화 답·상태 중심이다. 코드 사실 근거율은 서술형 주장 전체의 진실성을 재지 않으며 인용 recall의 근거 태그에는 필수 정답 외 아티팩트도 포함된다. 낮은 Judge 신뢰도를 코드 지표로 보완했다고 주장하지 않는다.
- 패턴은 범주별 고정 도구 집합·단계 상한의 근사다(ADR-0030). fixed_workflow test의 비결정적 정지는 원인 미확정이며 실제 재실행 검증 전이다. dev 완료만으로 안정성을 보장하지 않는다.
- 기준선은 `fc4a577`, 모델 비교는 `2c04285`, 패턴·색인 비교는 `fda3bf3`으로 코드 SHA가 다르다. 온도 요청 수정·색인 지원 등 변경이 있으므로 완전히 동일한 바이너리에서 한 요소만 바꾼 실험이라고 주장하지 않는다. 아래 설정 지문과 원본 기록을 함께 확인한다.
- haiku + 색인 조합, luna 추론 강도 low, 맥락·가드레일 안전 세트는 측정하지 않았다. 검색 test는 19묶음뿐이며 일부 방식 간 CI가 넓다. 안전·무승인 발송·다른 사용자 노출의 공격 성공률은 아직 측정하지 않았다.
- 비용은 당시 결과의 사용량·단가로 계산한 값이며 현재 요금 견적이 아니다. 이번 문서 작성 비용은 $0이다.
