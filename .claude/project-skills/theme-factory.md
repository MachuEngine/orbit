# Orbit 보충 규칙: theme-factory

> `.claude/skills/theme-factory/SKILL.md`(Anthropic 공식 스킬)보다 이 문서가 우선한다.

- 이 스킬은 슬라이드·문서용 프리셋 테마를 고르게 하는 스킬이다. **Orbit 화면의 팔레트·글꼴을 이 스킬의 프리셋 10개로 바꾸지 않는다.** 기준은 `docs/brand/brand-guide.md` 8절이다.
- 쓰는 것: 색 대비·서피스 위계·타이포 스케일을 점검하는 관점. 새 테마를 만들어야 한다면 대비를 계산한 후보를 만들고 `brand-identity` 스킬 절차(토큰과 가이드 기록)를 따른다.
- 원본의 "테마를 보여 주고 사용자 선택을 기다린다" 절차는 슬라이드용이다. 자율 위임 작업에서는 대비 결함을 고치는 범위(기존 토큰 값의 소폭 조정)만 스스로 적용하고, 팔레트·글꼴 교체는 하지 않는다.
