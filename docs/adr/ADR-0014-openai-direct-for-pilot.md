# ADR-0014 — 모델 파일럿은 OpenAI API를 직접 호출한다 (임시)

- 상태: 채택 (2026-11-11, 개발자 결정: OpenRouter 크레딧을 당장 충전할 수 없어 OpenAI API를 쓴다. 예산 10달러)
- 작성일: 2026-11-11
- 근거: ADR-0009 §1(LLM 인터페이스, OpenRouter 단일 제공자), 세부 설계 D9-2~D9-4 (비공개, `private-docs/`)

## 배경
ADR-0009는 모든 모델 호출을 OpenRouter 하나로 보내고 제공자 라우팅·데이터 수집 거부를 요청마다 고정하기로 했다. 개발자가 OpenRouter 크레딧을 당분간 충전할 수 없어, 3단계-E 모델 파일럿을 OpenAI API(크레딧 10달러)로 진행한다. 2026-11-11 기준 OpenAI 문서를 확인한 결과는 다음과 같다(출처: developers.openai.com의 models·pricing·your-data 문서).
- 현재 주력 텍스트 모델(`gpt-6-astra`, `gpt-6.1-sol`, `gpt-6.1-terra`, `gpt-6-luna`)은 모두 추론(reasoning) 모델이며, 날짜가 붙은 스냅샷 ID를 공개하지 않는다.
- 다수 모델이 도구 호출을 Responses API에서만 지원한다.
- API 데이터는 기본적으로 학습에 쓰지 않으며, 남용 감시 로그를 최대 30일 보관한다. 무보관(ZDR)은 사전 승인이 필요하다.

## 결정
1. `orbit.llm`에 `OpenAILLM`을 추가한다. Responses API를 쓰고 같은 `LLM` Protocol을 구현한다. `OpenRouterLLM`은 그대로 두고, 설정 `ORBIT_LLM_PROVIDER`(`openrouter` | `openai`)로 고른다. 호출 코드(비서 경로, 러너)는 바꾸지 않는다.
2. **모델 ID**: 설정 값은 `openai/<모델>` 형식을 유지하고(기존 검증 규칙), 어댑터가 접두를 떼어 호출한다. 스냅샷이 공개되지 않으므로 **응답의 실제 모델 값과 실행 날짜를 결과에 기록**하고, 응답 모델이 요청과 다르면 기존처럼 불일치로 처리한다. 이 경우 재현성은 ADR-0009의 기준보다 약하다는 점을 파일럿 결과에 명시한다.
3. **추론 설정**: 추론 강도(`reasoning.effort`)를 설정 값으로 고정하고 설정 지문에 넣는다. 모델이 `temperature`를 지원하지 않으면 어댑터는 `temperature`를 보내지 않고, 그 사실을 지문에 남긴다(값을 몰래 버리지 않는다).
4. **비용**: OpenAI 응답에는 비용이 없으므로 설정한 단가표(입력·캐시 입력·출력, 1백만 토큰당 달러, 출처와 확인 날짜 포함)로 계산한다. 추론 토큰은 출력으로 계산한다(문서에서 명시 확인을 못 해 보수적으로). 단가표에 없는 모델은 비용 미상으로 기록해 누적 상한이 토큰 상한으로 대체되게 한다(ADR-0009).
5. **데이터**: 파일럿은 합성 데이터만 쓴다. `store=false`로 요청한다. 실제 사용자 데이터를 OpenAI로 보내는 것은 이 ADR의 범위가 아니며, 운영 제공자는 OpenRouter 복귀 또는 별도 ADR로 정한다.
6. **예산**: 실험 누적 비용 상한을 설정하고(파일럿 전체 8달러 이하), 실행 전 사전 측정(과제 5개)으로 전체 비용을 추정해 개발자 확인을 받는다.

## 검토한 대안
| 대안 | 채택하지 않은 이유 |
| --- | --- |
| OpenRouter 크레딧을 기다림 | 일정이 막힌다. 어댑터 경계가 있어 제공자 추가 비용이 작다 |
| Chat Completions API | 다수 모델이 도구 호출을 Responses API에서만 지원한다 |
| 별칭 모델 ID 거부 유지 | 공개된 스냅샷이 없어 파일럿 자체를 할 수 없다. 응답 모델·날짜 기록으로 보완한다 |

## 결과
- 파일럿 결과는 "OpenAI 모델 중 선택"으로 범위가 좁아진다. OpenRouter로 돌아가면 같은 러너·데이터로 다른 제공자 모델을 추가 비교한다.
- 재검토 트리거: OpenRouter 크레딧 충전, OpenAI가 스냅샷 ID를 공개, 운영에서 실제 사용자 데이터를 보내야 할 때.
