# ADR-0015 — 임시 고정 모델: `openai/gpt-6.1-terra` (추론 강도 low)

- 상태: 채택 (2026-11-11, 임시. 개발자 방침: OpenAI 사용은 임시이며 OpenRouter 연결 후 여러 모델을 비교해 다시 정한다)
- 작성일: 2026-11-11
- 근거: ADR-0009(평가 기반), ADR-0014(OpenAI 직접 호출), `docs/pilot/results-2026-11-11.md`

## 결정
- 평가 대상(`assistant_v0`)과 개발·실험의 기본 모델을 `openai/gpt-6.1-terra`, `reasoning.effort=low`, temperature 미전송으로 고정한다.
- 근거: dev 36문항 × 3회에서 성공률 100%(묶음 단위 95% CI 100–100)로, luna 두 설정보다 짝지은 차이 +24~26%p(CI 하한 +8.8%p 이상)가 높다. 비용은 에피소드당 약 0.0053달러로 예산 안이다.
- 실행마다 응답 모델 값과 날짜를 결과에 기록한다(공개 스냅샷 없음).

## 검토한 대안
| 대안 | 채택하지 않은 이유 |
| --- | --- |
| `gpt-6-luna`(none 또는 low) | 비용은 약 15배 싸지만 인물·프로젝트 과제에서 실패가 많다. 저비용 기준선으로는 계속 쓴다 |
| 상위 모델(`gpt-6.1-sol`, `gpt-6-astra`) | 예산(10달러)을 넘을 위험이 크고, terra가 이미 dev를 모두 맞혀 차이를 측정할 수 없다 |

## 결과와 후속
- dev에서 천장 효과가 생겼다. 8단계 패턴 비교 전에 평가 데이터 v1(어려운 유형 추가)이 필요하다.
- 재검토 트리거: OpenRouter 연결(다제공자 비교), 평가 데이터 v1, OpenAI 모델 변경·가격 변경.
