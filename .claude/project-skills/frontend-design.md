# Orbit 보충 규칙

> `.claude/skills/frontend-design/SKILL.md`(Anthropic 원본, 하네스 스킬 팩 `ui-design`)의 원칙 위에 Orbit 화면에만 해당하는 규칙을 더한다. 둘이 충돌하면 이 문서가 우선한다. 화면 검토는 `.claude/skills/design-review/SKILL.md`와 `.claude/project-skills/design-review.md`를 따른다. 코드 규칙은 `.claude/skills/frontend-react/SKILL.md`를 따른다.

## 1. Orbit 화면의 성격
- Orbit은 마케팅 페이지가 아니라 **매일 쓰는 작업 도구**다. 채팅과 승인 화면은 표현보다 정확성, 읽기 쉬움, 일관성을 우선한다.
- 원본 스킬의 "히어로"와 "대담한 한 요소" 원칙은 랜딩·온보딩 화면에만 적용한다. 채팅 화면에서 대담함은 브랜드 색과 서체 같은 정체성 요소에 쓰고, 정보 배치는 조용하게 둔다.
- 사용자가 하루에 수십 번 보는 화면이므로 장식 애니메이션을 두지 않는다. 움직임은 사용자의 동작에 대한 반응(전송됨, 승인 대기, 실행 완료)에만 쓴다.

## 2. 디자인 토큰
- 색, 서체, 간격, 모서리 반경, 그림자는 `docs/brand/tokens.css`(또는 `tokens.json`)의 값만 쓴다. 컴포넌트에 hex 값이나 임의 px 글자 크기를 직접 쓰지 않는다.
- 토큰이 아직 없으면 `brand-identity` 스킬로 먼저 만든다. 임시 값으로 화면을 만들지 않는다.

## 3. 한국어 타이포그래피
- 본문 줄바꿈은 `word-break: keep-all`, `overflow-wrap: anywhere`로 어절 단위를 지키되 긴 URL·영문이 넘치지 않게 한다.
- 행간과 한 줄 길이는 브랜드 가이드(`docs/brand/brand-guide.md`) 값을 따른다. 가이드가 없을 때 기본값은 줄 간격 1.6~1.8, 한 줄 한글 40~50자 안팎이다(`brand-identity` 스킬과 같은 값).
- 한글 서체는 브랜드 가이드에서 정한 것을 쓰고, 한글이 없는 영문 서체만 지정해 한글이 시스템 기본 서체로 떨어지는 일을 막는다. 대체 서체 순서를 토큰에 정의한다.
- 영문 대문자 라벨(ALL-CAPS)은 한글 화면에서 어색하므로 쓰지 않는다.

## 4. 채팅 입력
- 한글 입력 중(IME 조합 중)에는 Enter로 전송하지 않는다. `compositionstart`/`compositionend` 또는 `KeyboardEvent.isComposing`으로 판단한다.
- 전송 중, 실패, 재시도 상태를 메시지 단위로 보여 준다. 실패 시 무엇이 실패했고 어떻게 다시 보내는지 문장으로 알린다.
- 스트리밍 응답은 화면이 위아래로 튀지 않게 자리를 유지하고, 사용자가 위로 스크롤해 읽는 중이면 자동 스크롤하지 않는다.

## 5. 승인 화면 (외부 쓰기 전 확인)
승인 화면은 사용자가 위험한 동작을 실행하기 전 마지막 방어선이다(세부 설계 D5-5, D6-1). 다음을 반드시 보여 준다.
- **무엇을 하는지**: 동작 이름을 동사로(“메일 보내기”, “일정 시간 변경”).
- **대상과 인자 요약**: 수신자, 제목, 일정 시간 변경 전후. 긴 본문은 접어 두되 펼쳐 볼 수 있게 한다.
- **출처 경고**: 인자 중 사용자가 직접 말하지 않고 메일·문서 본문에서 온 값(예: 처음 보는 수신자)은 눈에 띄게 표시하고 이유를 한 줄로 설명한다.
- **되돌릴 수 있는지**: 메일 발송은 되돌릴 수 없다고 명시한다.
- **만료**: 승인에 유효 시간이 있으면 남은 시간을 보여 준다.
- 승인 버튼 문구는 실제 동작과 같게 쓴다(“보내기”, “일정 변경”). “확인”, “승인” 같은 모호한 문구를 쓰지 않는다. 결과 알림도 같은 동사를 쓴다(“보냈습니다”).
- 화면은 승인 의사만 서버에 보낸다. 실행 여부는 서버가 판단하며, 화면이 직접 외부 API를 부르거나 실행을 확정하는 것처럼 보이게 만들지 않는다.

## 6. 외부 콘텐츠 렌더링 (D6-1)
- 메일·문서 본문의 외부 이미지와 링크는 자동으로 불러오지 않는다. 이미지는 "이미지 표시" 같은 명시적 동작 뒤에만 보여 준다.
- 링크는 실제 주소를 보여 주고, 표시 텍스트와 주소가 다르면 알린다.
- 외부 콘텐츠의 HTML은 정제(sanitize)한 뒤 렌더링하고, 스크립트·폼·iframe은 제거한다.

## 7. 문구
- 원본 스킬의 "글쓰기" 절을 따르되 한국어로 쓴다: 평서문, 군더더기 없는 동사, 사과하지 않는 오류 문구.
- 시스템 용어(워크스페이스 ID, 실행 기록) 대신 사용자가 이해하는 말(내 계정, 보낸 메일)을 쓴다.
